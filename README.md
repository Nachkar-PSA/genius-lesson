# 🥐 Modern Backer shop / Сучасна пекарня

Адаптивный лендинг для современной пекарни с использованием современных инструментов фронтенд-разработки.

## 🔗 Ссылки
- **Демо:** [Посмотреть проект](https://nachkar-psa.github.io)

## 🛠 Технологии в проекте
*   **HTML5** — семантическая верстка.
*   **SCSS** — использование переменных, миксинов и вложенности для чистого кода.
*   **JavaScript** — реализация интерактивных элементов (меню, слайдеры, формы).
*   **БЭМ** — методология именования классов для масштабируемости.

## 🚀 Особенности проекта
- Полная **адаптивность** (Desktop, Tablet, Mobile).
- Использование кастомных шрифтов и современной графики.
- Оптимизация изображений для быстрой загрузки.

## ⚙️ Как запустить локально
1. Клонировать репозиторий: 
   `git clone https://github.com`
2. Открыть файл `index.html` в браузере.
